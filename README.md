Навчальний сайт ACME Fashion House з репозиторію викладача:
https://gitlab.com/kipz_tov/a11y-practical-task

Вихідний commit: `3f6635817392acef9397d1b06c1766367eee6a3e`.
У власній історії тег `baseline` містить незмінений вихідний проєкт; `accessible-v2` містить виправлення HTML/CSS.

Власний репозиторій: https://github.com/ZaGOR-1/hmi-lab04-accessibility

## Запуск

Залежності для сайту не потрібні. Відкрити main.html і form.html безпосередньо у браузері або запустити:

```sh
python -m http.server 8000
```

Відкрити http://localhost:8000/main.html. Іконка користувача Create account відкриває form.html; Home і логотип повертають на main.html.

## Зміни

Для main.html виправлено title, en-GB, skip link із передачею фокусу, заголовки й орієнтири, порядок Tab, контраст, alt, семантику відгуків, назви посилань/кнопок і чотири списки футера. Для form.html пов’язано мітки, додано required до основних полів і семантичну групу доставки. Прапорець розсилки та доставка необов’язкові. Виправлено спільні елементи шапки й підписки.

Порожня або помилкова форма використовує нативну перевірку браузера. Для запуску цієї перевірки контейнер полів перетворено на form. Після успішної нативної валідації надсилання зупиняється, адже вихідний проєкт не містить сервера реєстрації. Персональні дані нікуди не передаються формою облікового запису.

## Докази

Каталог `evidence/` містить матрицю на 100 балів (без самостійно виставленої оцінки), 14 змін до/після, журнали axe-core, Nu Html Checker, клавіатурні сценарії, контраст і справжні скриншоти. `reports/` містить редагований DOCX та PDF.

Axe-core перевірено у Chromium. Клавіші натискалися через Playwright, це не сеанс тестування людиною. Справжній екранний зчитувач, WAVE й браузерні розширення не запускалися; інструкція для додаткового ручного проходу є в `evidence/needs-human-input.md`. Нуль автоматичних порушень не засвідчує повної відповідності WCAG.

## Межі вихідного прикладу

Збережено його каталог, зображення, тексти, ціни, історичні дати й призначення форми. Посилання `#`, відсутня `product.html`, кнопки товарів та категорії без бізнес-обробників залишаються навчальними заглушками. Не додано вигаданого магазину, кошика чи серверної реєстрації.

Походження вихідного завдання, вказане автором: [Introduction to Web Accessibility WCAG 2.1](https://www.udemy.com/course/introduction-to-web-accessibility-wcag21/?referralCode=05B73E4177FADAD9930A).

## Повторення перевірок

Сам сайт залишається статичним. Для перевірок окремо потрібні Node.js, Python, Java та Chromium для Playwright:

```sh
npm ci
npx playwright install chromium
npm run verify
```

Сценарій створює тимчасову копію `baseline` та поточного коду, запускає локальний HTTP-сервер і зберігає свіжі результати в `checks/verification/`. Цей каталог не додається до Git. Якщо Chromium уже встановлено, шлях можна передати змінною `CHROMIUM_PATH`. Для іншого порту встановити `LAB04_PORT`.
